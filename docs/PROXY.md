# 代理资源：第三方 SOCKS5 / 原始 SSTP

## 第三方 SOCKS5

1. 「接入 → 第三方 SOCKS5 → 添加代理」，填写地址、端口、账号密码，国家/城市/备注可选。
2. 保存后检测，确认「启用」和「加入订阅」已开启，再更新客户端订阅。
3. 密码不回显、不进订阅；编辑留空表示保留。

手填地区标为“手动标注”，实测出口与画像另存，不一致时提示。`unknown` 表示缺少分类证据，不称家宽。

## 原始 SSTP

「接入 → 原始 SSTP」复用官方候选，只导出通过且未过期的记录，含域名、端口、账号（均为 `vpn`）、观测时间和有效期。

文本示例：`sstp://vpn:vpn@vpn-example.opengw.net:443`。这是参数表示法，Windows 可新建系统 VPN（类型 SSTP）直接连接。数据不经过本 VPS，VPS 离线不影响已保存的独立连接。

v2rayN 订阅使用 VLESS，不能把 `sstp://` 当 VLESS 导入。
