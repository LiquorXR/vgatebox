# 产品与概念

这一页解释 vgatebox 的核心对象、状态和它们之间的关系。先理解这些，后面的“出口”“接入”“订阅”才不会混。

## 一句话模型

**候选**经过检测进入**节点池**；用户表达“要几个、什么策略”的**意图**；后台把意图收敛成**出口**；出口再通过**接入入口**暴露给客户端；**订阅**把可用接入聚合成一条客户端可导入的链接。

## 核心对象

| 对象 | 是什么 | 不是什么 |
| --- | --- | --- |
| 候选（candidate） | VPN Gate 官方 CSV 中的一条记录 | 不是已验证出口，不代表当前能连 |
| 节点池（node pool） | 当前候选清单及其检测结果 | 不是常驻隧道集合 |
| 出口（exit / Slot） | 由 vgatebox 管理的一条实际出网路径 | 不是候选，也不是客户端配置 |
| 接入入口（inbound） | 客户端连接 vgatebox 的监听端点 | 不是出口本身 |
| 订阅（subscription） | 可用接入的聚合链接 | 不是节点池列表 |
| 本机网络（host direct） | 从 VPS 公网 IP 直出的接入 | 不是其他出口的故障备用 |
| 第三方 SOCKS5 | 用户提供的外部 SOCKS5 上游 | 不是 VPN Gate 候选 |
| 原始 SSTP | VPN Gate 的 SSTP 参数导出 | 不是经过本 VPS 的 VLESS 入口 |

## 候选与节点池

候选来自 VPN Gate 官方 CSV。vgatebox 只保存候选的配置和元数据，不会因为“拿到候选”就自动认为它可用。

- 刷新来源会生成新的 `node_pool.json`；失败时保留旧清单。
- 检测是对候选的临时连接，验证出口 IP、延迟和内容；通过只代表**那次检测**，不等于长期在线。
- 检测结果带有效期；配置变化、过期或来源变化后会标记为 `stale`，不再当作现状。
- 候选数量 ≠ 可用出口数；同一批候选可能因为上游、地区、策略或并发限制而无法全部建连。

官方来源失败时，可以启用第三方镜像后备。镜像只提供**原始 CSV**，获取、校验、解析和检测仍在本 VPS 完成；不采用镜像的检测结论。详见 [节点池](../use/nodes.md)。

## 出口（Slot）

出口是 vgatebox 真正维护的运行单元。每个出口：

- 有稳定的 **Slot 编号**（`1..N`）和稳定的本机 SOCKS5 端口；
- 有自己的 network namespace、veth、`tun0` 和 OpenVPN 进程；
- 有独立的运行状态、策略、退出 IP、国家和证据；
- 可以绑定一个或多个接入入口；
- 可以被停止、恢复、换节点或删除。

“数量”是用户意图，不是当前运行数。后台会把实际状态收敛到目标数量；没有合适候选时，出口会以 `waiting_for_nodes` 占位，而不是随便拿一个候选或回退本机网络。

### 出口状态

| 状态 | 含义 | 是否接受新连接 |
| --- | --- | --- |
| `starting` | 正在建立 namespace、OpenVPN、出口基线和入站绑定 | 否 |
| `up` | 已通过运行验活并发布 | 是 |
| `degraded` | 仍可出网，但延迟超过策略或健康检查异常，后台观察/准备换节点 | 是 |
| `blocked` | 出口证据不满足策略、绑定失败或出口 IP 变化，流量被阻断 | 否 |
| `waiting_for_nodes` | 没有符合当前策略的候选，占位等待 | 否 |
| `failed` | 建连失败或不可恢复错误，后台按退避重试 | 否 |
| `stopped` | 用户显式停止，后台不会自动拉起 | 否 |

`up` 和 `degraded` 都算“可服务”；订阅只会输出 `up` 的 VPN Gate 入口。`unknown` 是 IP 类型的合法值，不等于“住宅”。

## 接入入口

“接入”是客户端连到 vgatebox 的方式。常见四类：

1. **本机网络**：内置 Xray 的一个直出入口，出口是 VPS 公网 IP。适合首次验证，也可长期使用。
2. **VPN Gate 入站**：每个出口自动创建一个 VLESS 入站，绑定到该出口。客户端连入站，Xray 把流量送到对应出口的 SOCKS5。
3. **第三方 SOCKS5**：保存外部 SOCKS5 地址和账号后，内置 Xray 生成一个 VLESS 入站，出站指向该 SOCKS5。订阅里看到的是 VLESS 链接，不是 SOCKS5 凭据。
4. **VPS SOCKS5**：把某个出口额外暴露成公网 SOCKS5，供其他电脑或程序使用；需要显式开启，且需要单独放行端口。

普通使用不需要进“高级接入”手动建入站。手动入站可以绑定已有出口，也可以暂时不绑定；未绑定的入口会阻断流量，不会悄悄直出。

### 自动入口与归档入口

- 自动入口由出口数量维护：新建出口时创建，删除出口时默认保留为“归档入口”，之后重建同一编号可以复用端口和凭据。
- 删除出口时勾选“同时清理归档入口”，会一并删除该 Slot 的自动入口；失败会在响应里报告。
- 出口已不存在但自动入口还在时，入口显示为“归档入口”，可单独清理。

## 订阅

订阅把**可服务的接入**聚合成客户端可导入的链接：

- 本机网络：按启用状态输出。
- 自定义代理：需要代理本身启用且“加入订阅”。
- VPN Gate：只输出 `up` 出口中已启用的入站；`degraded`、`blocked`、`waiting_for_nodes`、`failed`、`stopped` 不输出。

默认顺序是 **本机网络 → 自定义代理 → VPN Gate**。客户端需要主动更新订阅才能看到新增/删除的节点；地址不变时不需要重新导入。

订阅地址带独立 token，并且仍在随机访问路径之后。token 等同密码；重置后旧地址立即失效。详见 [订阅](../use/subscription.md)。

## 证据链

vgatebox 把“实测结论”和“人的标注”分开：

- **实测证据**：`checked_at`（何时测）、`expires_at`（何时失效）、`profile_sha256`（测的是哪份配置）、`actual_ip`、`observed_by`、`stale`。
- **出口画像**：出口 IP、国家、ASN/ISP、IP 类型、住宅/机房判断、查询时间、服务商和规则版本。
- **人的标注**：手填国家、城市、备注。它们只用于展示和命名，**不是**连通性或住宅类型的证据。

国家与 IP 类型分别判断：国家可以由独立的国家查询给出；IP 类型只有完整画像通过时才可信。画像缺失、过期或服务失败时，类型回到 `unknown`，不会沿用旧结论。

## 意图与对账

用户只表达意图：

```json
{
  "count": 6,
  "policy": {
    "country": "JP",
    "allowed_ip_types": ["strict_residential", "unknown"],
    "maximum_latency_ms": 1500
  },
  "server_name": "www.tesla.com"
}
```

这份意图保存在 `console.json`。后台每 15 秒检查一次，并在候选变化时唤醒：

1. 先处理中断的删除；
2. 从高编号往下缩容；
3. 按策略补足到目标数量；
4. 为新出口创建/复用入站并绑定。

崩溃重启后，从磁盘恢复意图和出口，而不是从当前运行态反推。删除是显式的：删除一个出口会同时把目标数量减 1，后台不会立刻重建它。

## 数据面与隔离

- 每条 VPN Gate 出口在自己的 network namespace 中运行 OpenVPN；namespace 内有独立 `tun0`、路由和 DNS。
- 母机上有一个仅监听 `127.0.0.1:<port>` 的 SOCKS5，它在 namespace 内建立出站连接；内置 Xray 通过这个 SOCKS5 使用出口。
- 公网 SOCKS5 是另一个独立的 Xray 入站，只有显式开启才存在；不要把内部 SOCKS5 端口当成公网入口。
- 主机侧有 iptables 转发规则和 kill switch；隧道断开或出口证据失效时，绑定它的入站会阻断，避免流量退回公网。
- 出口故障不会自动切换到本机网络；这是有意的安全选择。

## 常见误解

| 误解 | 实际 |
| --- | --- |
| “候选检测通过就能直接订阅” | 订阅只输出出口的入站；候选要通过建连成为出口 |
| “出口数量 = 可用数量” | 数量是目标；已就绪、等待、失败分开统计 |
| “本机网络是故障备用” | 它是独立入口，不会自动接管其他出口 |
| “手填国家就是国家证据” | 手填只用于展示；国家证据来自实测出口 IP 查询 |
| “unknown 就是家宽” | `unknown` 表示缺少分类证据，不能称为住宅 |
| “订阅地址可以随便发” | token 等同密码；泄露后可重置口令 |
| “Clash 和 v2rayN 订阅完全一样” | 两者字段表达能力不同；mKCP 只进 v2rayN 格式 |
