# VPS 自主获取与可选镜像后备

所有获取由用户 VPS 上的 Pool Builder 发起，先请求原配置来源；后备默认开启，来源失败才由同一 VPS 获取第三方镜像的原始 CSV，用户可关闭。候选筛选、VPN 连接与真实出口验证仍全部在该 VPS 完成，不采信镜像的 TCP/国家/住宅检测结果，不依赖 Cloudflare。

## 来源与默认

- 保留现有 source_urls、国家策略、并发、凭据和端口；新安装和未配置镜像字段的旧配置默认开启后备，已明确保存的关闭选择继续保留。
- 可选提供者为 GeorgeXie2333/vpngate-list-mirror（第三方，非官方）。只读取 HTTPS 索引和固定 40 位提交的原始 CSV，不执行对方代码，不下载其预验证节点池或检测结论。
- 内置顺序为原官方入口 `www.vpngate.net` → VPN Gate 下载域名 `download.vpngate.jp` 的同格式 HTTPS API → 第三方镜像。使用原内置入口的旧配置会在读取时补上官方备用地址，不改写私有文件；自定义来源或明确空列表保持原意。备用域名见 [官方论坛管理员给出的下载入口](https://forum.vpngate.net/viewtopic.php?t=1388) 和 [VPN Gate 下载页](https://download.vpngate.jp/en/download.aspx)。不使用 HTTP 镜像，不关闭证书校验，不把备用 IP 硬绑到主域名。
- 索引校验版本、提交、字节数、SHA256 和声明抓取时间；默认拒绝超过 24 小时、明显未来时间或比当前保留镜像清单更旧的快照。可在设置中明确调整最大年龄；超过 3 小时提示较旧。
- SHA256 只证明与该镜像索引一致，不能证明官方来源真实性。镜像提供者、VPS 获取时间及镜像声明时间分别展示。候选仍保持未检测/unknown。
- 镜像 OpenVPN 配置仅接受 VPN Gate 常见数据指令和内嵌 PEM，远端必须等于该行公开 IPv4；未知指令、外部文件、脚本、插件和混淆语法整行拒绝，不写入可连接的候选。不会执行镜像附带的程序。
- 请求等待设为有总预算的本地操作，官方来源超时不占满整个刷新期限；过期请求的返回结果不发布。镜像索引失败、摘要不符、过期或无合适候选时保留原清单，不伪造成功。

## 验证

覆盖默认开启、明确关闭保留、官方备用先于镜像、超时回退、声明时间/回退/哈希拒绝、拒绝继承镜像检测证据、本地配置原子保存和其他私有字段保留、界面开关与来源时间显示。使用受控 HTTP 传输与 HTTPS 夹具验证边界，再进行 Linux 本地 Builder 获取公开镜像的单独验证；合成与真实结果分别记录。真正 VPN 连通仍以用户 VPS 的实测为准。
