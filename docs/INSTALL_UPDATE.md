# Linux 安装与完整包在线更新

固定版本统一安装命令见 [README](../README.md#安装)，自动选择 APT 或 DNF，并在安装后显示随机管理地址和密码。VPN Gate 来源不可用时仍可完成安装；直出及第三方 SOCKS5 可由用户独立配置，VPN Gate 出口等待候选而不回落。用户可在候选页开启第三方镜像后备，清单获取及出口验证仍由自己的 VPS 完成，见 [来源说明](POOL_SOURCE_FALLBACK.md)。系统支持范围见 [系统兼容性](LINUX_SUPPORT.md)。卸载和独立卸载工具见 [卸载说明](UNINSTALL.md)。

## 运行要求

统一安装、命令行更新、网页在线更新使用同一完整包，包含控制台、管理程序、内置 Xray 和候选池工具。

系统为 Linux amd64、systemd，需 root 权限及 TUN/network namespace 能力。

统一入口支持 Debian 12/13、Ubuntu 22.04/24.04 和 CentOS Stream 9/10。安装器识别系统后分别使用 APT 或 DNF；CentOS 自动配置 EPEL 并构建校验过源码的 SSTP RPM。各系统范围、软件来源和容器验收限制见 [系统兼容性](LINUX_SUPPORT.md)。

## 安装与升级约定

- 下载固定发布标签对应完整包与 SHA256，检查归档路径、类型、重复项、文件清单和每个成员摘要；失败不替换现有部署。只有本项目官方 GitHub 发布资产作为默认来源。
- 同一台主机只运行一项部署。网页任务通过独立 systemd 单元执行，不受管理进程重启影响；重启前后可查询持久进度。命令行和网页共用安装入口与部署锁。
- 下载、依赖及本地候选配置检查尽量在原服务运行时完成。安装不请求 VPN Gate 来源，有旧池则保留，没有旧池也允许安装，不伪造清单或更新时间；候选由后台刷新或定时器获取，配置、文件系统及程序错误仍中止。升级时停止本项目候选刷新和管理服务，创建一致的完整私有项目备份，再检查旧状态和替换完整程序、Python 工具、Xray 与服务文件。
- 保留管理路径/密码/端口、订阅口令、Slot 身份/凭据/策略/启停、接入配置、直出/外部 SOCKS 设置、检测并发和 SSTP 设置/结果；原有配置不套用新安装默认值。
- 通过本地登录与管理 API 检查实际运行版本。安装或健康检查失败时恢复本项目备份和原服务状态；恢复失败保留恢复记录、报告需要处理，不宣称成功。未完成部署在下次操作时先恢复。备份仅覆盖本项目受管文件，不是操作系统镜像，不回滚系统依赖包。
- 服务状态快照先查询 systemd LoadState，尚不存在的项目 unit 记为未运行/未启用，不执行会产生误导报错的 is-enabled 查询；systemd/bus 查询失败仍报错并停止安装，不能伪记为已停用。
- 新系统首次安装创建随机管理路径、密码和订阅凭据，并默认开启 VLESS/REALITY 本机直出。未设置 VPN Gate 数量且无旧 Slot 时，取得候选后自动保存并创建 16 个目标出口，按原并发连接和绑定；没有候选时等待，未验证出口不发布订阅。已有数量（含 0）、端口、凭据、策略和直出开关保留，不自动故障回落。普通使用无需全量检测或手动新建入站；见 [首次使用](FIRST_USE.md) 与 [默认出口](AUTO_DEFAULT_EXITS.md)。

## 用户入口

README 的一键命令在安装成功后自动执行 `vgatebox access`，直接显示本机私有管理地址和初始密码。首次安装生成独立随机路径、密码和订阅凭据；该查看命令不重置凭据，已有更新保留原值。`vgatebox version` 查看安装版本，`vgatebox check-update` 检查正式更新，`vgatebox update` 更新完整部署；网页“设置 → 版本与更新”提供检查、执行及进度。

完整安装命令、首次登录与更新操作见 [README](../README.md) 和 [VPS 文档](../vps/README.md)。重装系统前请将私有备份另存至其他设备。

## 验证范围

合成回归覆盖新目录安装、旧配置保留、包校验拒绝、并发锁、候选下载失败不停止旧服务、状态检查失败、替换/启动失败恢复、恢复失败保留、未完成部署恢复及更新任务状态。真实 Linux 验收覆盖独立新工作目录管理和订阅、完整包迁移、独立 systemd 在线更新和公开 Release 下载/校验。

## 全新系统验收清单

1. 用户重装 Debian 12 amd64，核实新的 SSH 主机指纹，再以 root 执行 README 的固定版本安装命令；不关闭 SSH 主机身份检查。
2. 确认 `vgatebox version` 为 v1.1.2，管理服务及候选刷新定时器正常；执行 `vgatebox access`，开放实际管理端口后登录。
3. 不导入旧备份，确认生成了新的私有路径、管理密码与订阅；首次默认直出应已开启，在 v2rayN 更新默认订阅并实际访问 HTTPS，出口应为 VPS IP。既有安装保留原开关。
4. 设置需要的目标出口数和检测并发，刷新候选并检测，验证进度、手动优先、去重及取消。先使用不限国家且允许 unknown 的技术策略验收；没有画像证据不标家宽。上游供给不足如实等待。
5. VPN Gate 出口可用时验证订阅对应实际 IP、国家命名、外部 SOCKS；停止出口后对应连接失败，本机直出独立可用，不自动回落。
6. 在代理资源测试原始 SSTP；只导出通过且未过期的私有结果。不要求每个国家、候选或固定数量成功。
7. 检查更新：当前最新版应显示无需更新；新正式版发布后可在网页执行完整包更新，重新登录查看完成结果并确认原订阅及设置保留。

全新工作目录、已有系统升级、全新操作系统分别记录；前两项测试不替代用户重装后的最终验收。
