# 首次使用：从登录到客户端上网

安装与 VPN Gate 节点筛选独立。首次安装默认开启本机网络，已有安装保留原开关；也可添加第三方 SOCKS5。没有候选的 VPN Gate 出口继续等待，系统会定时重试，也可点击刷新来源。

**不需要先把全部候选测完，也不需要手动新增入站。** 建议先用本机网络验证客户端，再按需要添加 VPN Gate 或自有代理；已有就绪出口时可直接从第 3 步导入订阅。

1. **登录管理页。** 使用安装完成时显示的地址和密码；忘记地址时在 VPS 执行 `vgatebox access`。总览提供「刷新候选 → 等待就绪 → 复制订阅 → 导入使用」的状态化步骤和快捷操作。
2. **检查基础连接。** 首次安装默认开启「VPS 本机网络」；旧安装已关闭时可手动点击「启用」。此入口使用服务器公网 IP，可在没有 VPN Gate 节点时验证客户端接入；它不会成为其他出口的故障备用。
3. **把订阅添加到客户端。** 在「订阅」选择格式：v2rayN 使用默认格式，Clash Verge / Rev 使用 Clash/Mihomo 格式，再点击「复制订阅链接」。在客户端新建订阅或远程配置、粘贴地址并更新；选择 `VPS 本机网络`（或已就绪出口），启用客户端的系统代理或相应代理模式，再访问网页验证。服务器防火墙须允许管理页显示的实际**接入端口**（公开 SOCKS5 还需同时放行 UDP），只开放 8899 管理端口不足以连接代理。重装系统后须使用新订阅地址。
4. **使用 VPN Gate 出口。** 首次没有保存数量且没有旧 Slot 时，取得候选后自动创建 6 个出口，按当前并发依次连接并绑定 VLESS / XHTTP / REALITY 接入入口，无需先设置数量。已有数量（包括 0）和旧 Slot 保留；可在「出口 → 调整数量」修改目标和国家。等待出口「已就绪」，再更新客户端订阅选择使用；候选不足或连接失败显示等待，不保证当时能凑齐 6 个可用出口。unknown 仅表示缺少分类证据，不称家宽。
5. **有自己的固定代理时再添加。** 在「接入 → 第三方 SOCKS5」填写地址、端口、账号密码，可选国家、城市与备注；保存后检测，确认「启用」与「加入订阅」已开启，再更新客户端订阅。详见 [代理资源](PROXY.md)。
6. **其他资源按需使用。** 「节点池」用于刷新来源、单条或批量检测及排障，不是订阅的前置步骤。「接入 → VPS SOCKS5」供其他电脑或程序通过本 VPS 接入，需显式开启外部端口；「原始 SSTP」导出给支持 SSTP 的客户端，自身不是可直接导入 v2rayN 的 VLESS 订阅。普通使用无需进入「接入 → 高级接入」新增入口；自行新增的入口须绑定已有出口，未绑定时阻断流量。

### 页面状态怎样看

「节点池 → 周期任务」可开启或关闭来源刷新：刷新默认 60 分钟、最短 30 分钟，任务结束后重新计时，重启保留时间。每次刷新成功后自动全量检测一次候选（沿用当前并发）；失败保留旧清单不触发检测。检测结果有效期固定 30 分钟，超期显示“结果已过期”；手动检测随时可用。Clash 用户在「订阅」选 Clash/Mihomo 格式再复制链接，v2rayN 保持默认格式。

刷新来源会显示等待秒数和不确定进度条，结束后显示本次成功/失败、完成时间和候选数量；“上次成功获取”只随清单成功生成变化。相同数量可能是正常结果，刷新成功也不代表候选已通过 VPN 连通检测。

原来源超时后会尝试第三方镜像后备，默认开启，可在「来源设置」关闭。镜像只提供候选，获取与验证仍在自己 VPS 完成。

| 页面或提示 | 含义与下一步 |
| --- | --- |
| 候选「检测通过」 | 表示那次临时连接通过；观察有效期内（默认至少 30 分钟，随检测间隔自动延长）会优先用于新出口选点，正式连接仍重新验活。不会把每个候选自动变成常驻出口。配置变化后排序提示失效。 |
| 出口「连接中 / 等待候选」 | 当前还不能提供该出口的订阅连接，等待就绪或查看检测原因；不需要反复新建入站。 |
| 出口「已就绪」 | 当前连接已经通过运行验活，可更新客户端订阅获取入口；不保证上游永久在线。 |
| 「地区未知」或 unknown | 国家或类型缺少可信证据，与当前连通状态分开判断；「地区未知」且「已就绪」可以同时出现，不能称为已验证家宽。 |
| 订阅选项变灰 | 勾选「全选」时单项由全选控制；取消相应全选后可逐个选择。VPN Gate 实际只输出已就绪入口。 |
| 新建入站「未绑定」 | 只有客户端接入配置，没有出口，连接会阻断；新增时可选择已有出口，等待或停止的出口也能预先绑定。只有该出口就绪后才可通行。 |

订阅默认按本机网络 → 自定义代理 → VPN Gate 排列；客户端需主动更新订阅获取变化，再手动选择使用的节点。VPN Gate 和自定义代理故障时阻断，不自动切换本机网络。指定国家暂时没有合适 IP 时保留策略等待，不强求国家或出口数量。

「节点池」的检测与正式 OpenVPN 建连共享「检测与建连并发数」；恢复连接优先，等待名额显示等待，已有稳定隧道不占建连名额。调低后让进行中的任务完成，不强断连接；配置很高仍需主机资源支持。

「接入 → 高级接入」以列表展示自动入口、手动入口、归档入口和本机网络，可配置或启停。自动入口由出口数量维护，可直接删除对应出口（目标数量随之减少 1）；删除时可勾选“同时清理归档入口”，不勾选则保留该编号的自动入口和凭据，之后重建同一出口时复用。出口已不存在时，自动入口显示为「归档入口」，可单独执行「清理入口」。手动入口可直接删除，停用入口保留端口与凭据。普通使用无需手动新增。

国家使用实测出口 IP 查询，默认通过正常 HTTPS 请求 [country.is](https://country.is/) 并严格比对返回 IP，缓存一天；失败短暂退避，缺失时显示地区未知。`COUNTRY_URL_TEMPLATE` 可在私有 `intelligence.env` 中替换兼容 JSON 服务（含 `{ip}`）或设空关闭；不向国家服务发送画像密钥。国家证据不证明住宅属性，未配置可信分类服务时类型仍为 unknown。

操作细节见 [代理资源](PROXY.md) 和 [VPS 文档](../vps/README.md)。
