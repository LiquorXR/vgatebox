# 出口

「出口」页把三种去向放在一起：**本机网络**、**自定义代理**、**VPN Gate**。VPN Gate 出口就是本页要管理的 Slot：每条出口有自己的隧道、端口、策略和状态。

## 数量与策略

### 调整数量

1. 打开「出口」，点「调整数量」。
2. 填写目标数量、国家/IP 类型/ISP/ASN/延迟策略，以及 REALITY 目标域名。
3. 保存后，后台按目标数量补齐或缩容；不会一次删掉所有旧出口。

首次没有保存数量、也没有旧出口时，取得候选后默认创建 **6** 个出口。已有数量（包括 0）会保留；数量 0 表示明确不要 VPN Gate 出口。

数量上限分为两层：

- `maximumSlots = 16384` 是实例地址空间和 `/30` 链路的上限，**不是**单机实际能承载的数量。
- 启动日志的“容量预检”按 fd、可用内存和端口区间给出建议值；它只提示，不修改 `-max`。实际容量还受 OpenVPN 进程、netns/veth、内核内存和上游质量影响。见 [容量与资源](../operate/capacity.md)。

### 策略字段

| 字段 | 含义 | 说明 |
| --- | --- | --- |
| 国家 | 两位国家码，如 `JP`、`US`；留空不限 | 以实测出口 IP 的国家证据为准 |
| 允许的 IP 类型 | `strict_residential`、`unknown` | `unknown` 必须显式允许；不能把未知当住宅 |
| 首选 ISP | 优先选择但非硬性 | 只有完整画像通过时才生效 |
| 允许/阻止 ISP | 硬性过滤 | 缺少 ISP 证据时不会被当作满足 |
| 允许/阻止 ASN | 硬性过滤，格式 `AS12345` | 缺少 ASN 证据时不会被当作满足 |
| 最大延迟 | 本机 SOCKS 延迟上限，0 表示不限 | 单次超限先观察；持续超限才换节点 |

手填的国家、城市和备注只用于展示和命名，**不是**策略证据。策略保存后，运行中的出口会重新验活；不满足策略的出口进入 `blocked`，不会带着旧证据继续服务。

### 策略回滚

每个出口保留上一份策略。修改后如果新策略导致出口无法就绪，可以在出口详情里回滚到上一份策略；回滚同样会重新验活。

## 状态怎么读

| 显示 | 含义 | 建议 |
| --- | --- | --- |
| 已就绪 | 已通过运行验活，可接受新连接 | 可以更新客户端订阅 |
| 连接中 | 正在建立 namespace/OpenVPN/基线 | 等待；不要重复新建 |
| 等待候选 | 没有符合策略的候选，占位等待 | 刷新候选、放宽国家或允许 `unknown` |
| 已降级 | 仍可出网，但延迟或健康检查异常 | 观察；持续异常会自动换节点 |
| 已阻断 | 证据不满足策略、绑定失败或出口 IP 变化 | 查看详情原因；修策略/重启/换节点 |
| 失败 | 建连失败或不可恢复错误 | 后台会退避重试；也可手动更换 IP |
| 已停止 | 用户显式停止 | 需要时在详情里恢复 |

`已就绪` 不保证上游永久在线；VPN Gate 是志愿者节点，掉线很常见。健康检查会周期性验活，连续失败后自动换节点。

## 更换 IP

在出口详情里点「更换 IP」：

- 保持 Slot 编号和本机 SOCKS5 端口不变，已分发的客户端配置继续可用。
- 优先避开刚用过的节点，并按当前策略重新选点。
- 如果该出口正在执行其他操作，请求会排队，当前连接完成后执行。
- 更换后会重新建立基线、画像和入站绑定；完成后状态回到「已就绪」。

## 停止、恢复与删除

| 操作 | 行为 |
| --- | --- |
| 停止 | 显式停止该出口，后台不会自动拉起；绑定入口阻断 |
| 恢复 | 重新建立隧道并验活 |
| 删除 | 删除该出口，并把目标数量减 1，后台不会立刻重建同一编号 |
| 调整数量 | 只改目标数量；不指定删除哪个编号 |

删除自动出口时：

- 默认保留该出口的自动入口作为「归档入口」，之后重建同一编号时可以复用端口和凭据。
- 勾选「同时清理归档入口」会一并删除该编号的自动入口；清理失败会单独报告，不影响出口删除结果。
- 手动入口和本机网络入口不受这个选项影响。

如果仍有等待中的出口，删除后目标数量仍可能由其他候选补位；删除的是指定编号，缩容是另一条路径。

## 自动入口与绑定

每个 VPN Gate 出口会自动创建一个 VLESS 入站，并绑定到该出口：

- 出口就绪后，入站才可通行；出口阻断时，入站也阻断。
- 出口换节点时，入站会跟着重新绑定，端口和客户端凭据保持不变。
- 自动入口由出口数量维护；不要手动删除正在使用的自动入口。要减少出口，用「调整数量」或出口详情的删除。
- 出口已删除但入口还在时，入口显示为「归档入口」，可在「接入 → 高级接入」单独清理。

手动入口可以绑定到已有出口（包括等待/停止的出口），也可以暂时不绑定。未绑定的入口会阻断流量，不会悄悄直出。详见 [高级接入](inbounds.md)。

## 失败原因

出口详情会显示最近的错误和阶段。常见原因：

- `waiting_for_nodes`：候选为空、候选不满足国家/IP 类型/ISP/ASN/延迟策略，或候选都在被其他出口占用。
- `blocked`：画像过期、实际出口 IP 变化、策略不满足、入站绑定失败。
- `failed`：OpenVPN 建连失败、端口/namespace 资源不足、上游不可达。
- 频繁掉线：10 分钟内多次重连后会自动降频，避免对上游造成压力。

对应处理见 [故障排查](../operate/troubleshooting.md)。
