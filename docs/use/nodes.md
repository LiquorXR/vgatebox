# 节点池：来源、检测与周期任务

「节点池」页管理候选从哪来、怎么检测、什么时候自动刷新。它**不是**订阅的前置步骤：普通使用只需要等待出口就绪；这一页主要用于刷新、排障和调整检测策略。

## 候选与可用出口的区别

- **候选**是 VPN Gate 官方 CSV 中的记录，只代表来源提供了这个节点。
- **检测通过**只代表那次临时连接成功；结果有有效期，过期后标记为 `stale`。
- **出口**是真正建立的常驻隧道；只有出口「已就绪」才会进入订阅。
- 候选数量不等于可用出口数；同一批候选可能因为地区、策略、上游或并发限制而无法全部建连。

## 刷新来源

### 手动刷新

在「节点池」页点刷新，或在 VPS 上执行：

```sh
vgatebox refresh
```

手动刷新不受自动刷新开关限制；它会取消正在运行的检测（旧结果会因新候选而失效），成功后把新候选标记为“已覆盖”，不会额外触发一次自动检测。

### 自动刷新

「节点池 → 周期任务」可以开启或关闭来源刷新：

- 默认 **60 分钟**一次，最低 **30 分钟**，最高 525600 分钟；关闭后不自动刷新。
- 同一自动任务不重叠；任务结束后重新计时，重启保留时间。
- 刷新失败保留旧候选清单，不触发检测；下一轮按保存的间隔重试，界面显示原因。
- 系统定时器 `vgatebox-pool.timer` 每 30 分钟触发一次 `toolbox.py pool --scheduled`；是否真正请求来源由控制台保存的间隔决定。

刷新过程会显示等待秒数、本次成功/失败、完成时间和候选数量；“上次成功获取”只随清单成功生成变化。相同数量可能是正常结果。

### 第三方镜像后备

官方来源失败时，可以启用第三方镜像后备：

- 默认开启；在「节点池 → 来源设置」关闭。
- 镜像只提供**原始 CSV**；VPS 自行下载索引、校验 `sha256` 和文件大小、检查快照年龄/回滚，然后按官方格式解析。
- 不采用镜像的检测结论；候选仍需本机检测，出口仍需本机建连。
- 默认最大快照年龄 24 小时；超过后拒绝使用。
- 已有明确保存的关闭选择会保留。

镜像不改变“自己的 VPS 优先请求原来源”的顺序。来源信息会记录在候选池的 `source` 字段里，界面会标注官方、官方备用或镜像。

## 检测候选

### 检测什么

一次检测会临时建立连接，验证：

- 能否通过候选建立隧道；
- 实际出口 IP 是否有效且不是 VPS 自己的 IP；
- 能否通过出口访问 HTTPS 内容；
- 延迟（本机 SOCKS 测量）；
- 可选：IP 类型画像（国家、ASN/ISP、住宅/机房）。

检测不会把候选变成常驻出口，也不会因为“检测通过”就自动创建出口。

### 手动检测

- 单条检测：候选行的「检测」。
- 批量检测：选择范围后「检测全部」或按筛选结果检测。
- 检测可取消；取消后状态为 `cancelled`，不会自动重跑。
- 检测与正式 OpenVPN 建连共享「检测与建连并发数」；正式出口恢复优先，检测等待名额时显示 `deferred`。

### 并发与 TTL

「节点池 → 检测设置」可以调整：

| 设置 | 默认 | 范围 | 说明 |
| --- | --- | --- | --- |
| 检测与建连并发数 | 2 | 1 到实例 `/30` 地址容量 | 检测和正式建连共用；调低后让进行中的任务完成，不强断连接 |
| 检测 IP 类型 | 关闭 | 开/关 | 开启后候选检测会查询 IP 类型；出口建连**始终**查询，不受此开关影响 |
| 排序观察有效期 | 30 分钟 | 1–1440 分钟 | 用于候选排序；实际结果有效期固定 30 分钟 |
| IP 类型缓存 | 24 小时 | 1–168 小时 | 同一 IP 的画像缓存 |

检测结果有效期固定 **30 分钟**：超期显示“结果已过期”，只影响展示和排序引用；正式出口建连仍会做完整 live 验证。配置变化（来源、策略、节点配置摘要）会让旧结果失效。

## 候选列表

「节点池」页支持：

- 按国家、状态、IP 类型、来源（志愿者/自营）筛选；
- 按延迟、速度、会话数排序；
- 查看单条详情、检测结果、证据时间与过期状态；
- 分页：前端首屏 200 条，按 `next_offset` 加载更多；不带 `limit` 的 API 请求返回全量。

`unknown` 表示缺少分类证据，不是“住宅”。`source_residential` 是来源标签（志愿者或 VPN Gate 自营），不等于出口 IP 类型；出口策略以实测画像为准。

## 国家与 IP 类型证据

- **国家**：默认通过 HTTPS 请求 `country.is`，严格比对返回 IP，缓存一天；失败短暂退避，缺失时显示“地区未知”。可用 `COUNTRY_URL_TEMPLATE` 替换为兼容 JSON 服务（含 `{ip}`）或设空关闭。
- **IP 类型**：通过 IPPure 或自定义画像服务查询，结果带服务商、查询时间、规则版本和过期时间；缺失时为 `unknown`。
- 手填国家、城市和备注只用于展示/命名，不是证据。
- 国家与住宅类型分别判断；`unknown` 不能被当作已验证住宅。

配置文件和校验命令见 [配置参考](../reference/configuration.md) 与 [VPS 运行目录](../reference/state-and-files.md)。

## 周期任务

「节点池 → 周期任务」设置：

- 来源刷新开关与间隔（默认 60 分钟，最低 30 分钟）。
- 刷新成功后自动做一次**全量检测**；同一候选池只检一次，手动全量检测也计入。
- 刷新失败不触发检测；旧候选保留。
- 检测结果 30 分钟过期，下一轮刷新（默认 60 分钟）会重新覆盖。
- 自动任务不重叠；手动刷新会取消正在运行的检测，但不会额外触发自动检测。

页面会显示下一次刷新/检测时间、上次完成时间、候选数、通过数和等待原因。检测时间估算会随候选数量和并发变化。

## 命令行

```sh
# 手动刷新候选（不触发自动检测）
vgatebox refresh

# 直接运行候选构建器（本地 .env / config/settings.json）
python3 scripts/toolbox.py pool

# 用本地官方格式 CSV 构建，不访问来源
python3 scripts/toolbox.py pool --csv-file /absolute/path/vpngate.csv

# 校验画像配置（不泄露 token）
python3 scripts/toolbox.py check-intelligence --ip 1.2.3.4 --refresh
```

完整的参数和退出码见 [CLI 参考](../reference/cli.md)。

## 失败与排障

| 现象 | 检查 |
| --- | --- |
| 刷新一直失败 | VPS 能否访问官方来源；来源设置是否关闭了镜像；`vgatebox refresh` 的 stderr |
| 刷新成功但候选为 0 | CSV 格式、筛选条件、镜像快照年龄；解析错误会记录在候选池 `source.errors` |
| 检测大量 `deferred` | 并发被正式出口占用；等待或降低目标数量；不要强杀隧道 |
| 检测通过但出口一直等待 | 国家/IP 类型/ISP/ASN/延迟策略过严；放宽策略或换地区 |
| 结果很快过期 | 固定 30 分钟 TTL；重新检测或等待下一轮自动检测 |
| 镜像来源可疑 | 关闭镜像后备；只使用官方来源，失败时保留旧候选 |

更多排障路径见 [故障排查](../operate/troubleshooting.md)。
