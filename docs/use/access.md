# 接入：本机网络、VPS SOCKS5、第三方 SOCKS5

「接入」页管理客户端连到 vgatebox 的方式。页面上有四个 tab：**VPS SOCKS5**、**原始 SSTP**、**第三方 SOCKS5**、**高级接入**；「本机网络」在「总览」和「出口」页开关。

| 接入方式 | 位置 | 流量路径 | 适用场景 |
| --- | --- | --- | --- |
| 本机网络 | 总览 / 出口 | 客户端 → Xray → VPS 公网 IP | 首次验证、不需要额外出口 |
| VPS SOCKS5 | 接入 → VPS SOCKS5 | 客户端 → VPS SOCKS5 → 出口 | 其他电脑/程序直接用 SOCKS5 |
| 第三方 SOCKS5 | 接入 → 第三方 SOCKS5 | 客户端 → Xray → 你的 SOCKS5 → 目标 | 已有固定代理，想并入订阅 |
| VLESS 入站 | 接入 → 高级接入 | 客户端 → Xray VLESS → 出口 | 自动/手动 VLESS 入口管理 |
| 原始 SSTP | 接入 → 原始 SSTP | 客户端 → VPN Gate SSTP（不经过 VPS） | 支持 SSTP 的客户端 |

## 本机网络

本机网络是内置 Xray 的一个直出入口，使用 VPS 公网 IP 出网。

- 首次安装默认开启；已有安装保留原开关。
- 在「总览 → VPS 本机网络」或「出口 → 本机网络」启用/停用。
- 它独立加入订阅，节点名默认 `VPS 本机网络`，可在出口页改订阅名称。
- 它不是其他出口的故障备用：VPN Gate 或第三方代理故障时，对应连接阻断，不会自动切到本机网络。

本机网络适合先验证客户端、端口和防火墙。确认能上网后，再创建 VPN Gate 出口或添加第三方 SOCKS5。

## VPS SOCKS5

VPS SOCKS5 把某个**已就绪**出口额外暴露成一个公网 SOCKS5 入口，供其他电脑、浏览器或程序使用。

### 开启

1. 打开「接入 → VPS SOCKS5」。
2. 找到目标出口；只有「已就绪」的出口可以开启。
3. 点「开启」；系统会分配一个外部端口，并复用该出口的 SOCKS5 凭据。
4. 在「详情」里查看/复制完整地址，或改账号口令。两项都留空保存会随机重置。
5. 防火墙放行该外部端口；公开 SOCKS5 的 UDP 能力取决于实现和防火墙，需要 UDP 时同时放行 UDP。

### 地址示例

```text
socks5://<账号>:<口令>@<VPS公网IP>:<外部端口>
```

- **内部端口**是出口在本机 `127.0.0.1` 上的 SOCKS5 端口，只供内置 Xray 使用，不对外。
- **外部端口**是额外的 Xray SOCKS 入站，只有显式开启才存在。
- 出口停止、阻断或删除后，外部 SOCKS5 也会失效。
- 账号口令是公网入口的唯一门槛；不要使用弱口令，也不要把地址发到公开位置。

### 与订阅的关系

VPS SOCKS5 **不进入** v2rayN/Clash 订阅；它是给非订阅客户端用的独立入口。订阅里仍然只有 VLESS 入口。

## 第三方 SOCKS5

第三方 SOCKS5 是你自己提供的固定上游。vgatebox 保存地址和凭据，内置 Xray 生成一个 VLESS 入站，出站指向这个 SOCKS5；客户端订阅里看到的是 VLESS 链接。

### 添加

1. 打开「接入 → 第三方 SOCKS5」，点「添加代理」。
2. 填写：
   - **服务器域名或 IP**：不要带 `socks5://`、路径或空格。
   - **端口**：1–65535。
   - **账号 / 密码**：SOCKS5 认证凭据，必填；密码不回显，编辑时留空表示保留。
   - **国家代码 / 城市 / 备注**：可选，只用于展示和命名；手填不是检测证据。
   - **启用**、**加入订阅**：保存后仍可在列表里切换。
3. 保存后点「检测」。检测会临时通过该 SOCKS5 访问 HTTPS，记录实际出口 IP、延迟、国家/IP 类型证据。
4. 确认「启用」和「加入订阅」都开启，再更新客户端订阅。

### 状态与证据

- 检测通过只代表那次检测；结果有有效期，过期后显示 `expired`，国家/类型回到未知。
- 手填国家/城市标为「手动标注」；实际出口与手填不一致时会提示，但不会把手填改成实测。
- 缺少分类证据时 IP 类型为 `unknown`，不能称为住宅。
- 修改地址、端口或凭据后，旧检测结果立即失效，需要重新检测。

### 安全

- 供应商账号和密码只保存在 VPS 私有状态里，不进入客户端订阅。
- 流量经本 VPS 转发；VPS 离线时该代理不可用。
- 第三方 SOCKS5 的 UDP 能力取决于上游；不要假设它一定支持 UDP。

## 高级接入

「接入 → 高级接入」管理 VLESS 入站的列表、自动入口、手动入口、归档入口和本机网络入口。普通使用不需要手动新建；需要自定义传输、端口、客户端或绑定关系时，见 [高级接入](inbounds.md)。

## 原始 SSTP

「接入 → 原始 SSTP」导出 VPN Gate 的 SSTP 参数，供 Windows 等支持 SSTP 的客户端直接连接。数据不经过本 VPS，VPS 离线不影响已保存的独立连接。详见 [原始 SSTP](sstp.md)。

## 防火墙与端口

- 管理端口默认 `8899`；接入端口由入口决定，可能是随机端口，也可能是你手动指定的端口。
- 客户端连接的是**接入端口**，不是管理端口；只放行 8899 不足以让代理工作。
- VPS SOCKS5 的外部端口、手动 VLESS 入站的端口都需要单独放行。
- 系统防火墙（`ufw`、`firewalld`、`iptables`）和服务商安全组都要检查。
- 如果使用反向代理，只代理管理页面时，节点链接优先使用 `FANOUT_PUBLIC_IP` 或自动探测到的公网 IPv4；详见 [安全](../operate/security.md)。
